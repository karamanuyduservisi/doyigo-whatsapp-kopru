# DoyiGo WhatsApp Köprü

Android test uygulaması. WhatsApp veya WhatsApp Business hesabını seçerek bir restoran numarası için mesaj hazırlar. Mesajı otomatik göndermez; gönderme işlemi WhatsApp içinde kullanıcı tarafından onaylanır.

APK, GitHub Actions üzerinden derlenir. Canlı DoyiGo sitesiyle bağlantısı yoktur.
